# RQM-0001 · HTML PPT 模板组

> 项目：`html-ppt-template` · 类型：`template` · 状态：已交付 · 版本：1.0.0
> 创建：2026-11-04 · 来源：用户原始需求

## 1. 原始需求（原文留档，不改写）

> 我需要在这个项目中新建一组html的ppt模板，带动画效果，允许openclaw调用生成内容，要求一份内容可以自适应导出16:9（横板内容） 4:3（横板封面） 3:4（竖版封面） 3:5（竖版内容）的动态自适应，遵循Go-Backend-Core中项目管理规范（该项目作为前端模板出现），下面是一些可以参考的东西
>
> @media (orientation: portrait) @media (orientation: landscape)
>
> lieflat-html-design：包含 11 组小红书长文模板（默认中文，适合导出 3:5 竖图）和 11 组封面模板（3:4 首图），覆盖杂志风、极客风、咨询报告风等，AI 可以直接调用模板生成，并自动截图输出 PNG，拿着图就能发。
>
> html-ppt-xhs-post：专做 9 页 3:4 竖版图文（810×1080），暖色 pastel、虚线 sticker 卡片、底部页码点点的风格，面向小红书图文轮播场景。
>
> any2card：可以把任意文本或 URL 转成适合小红书发布的信息卡片，支持竖版、正方形、横版，并能“自动决定”版式，适合把 408 知识点摘要做成卡片。
>
> ppt-html-template：零依赖的 16:9 比例 HTML PPT 模板，专为 AI 编辑器（Cursor、Trae 等）设计，响应式适配桌面、平板和手机，直接打开 index.html 即可使用，AI 按模块化结构逐页生成。
>
> AI-Animation-Skill：面向 B 站科普/技术分享场景，模式一就是“PPT 演示”，AI 先把你提供的 408 文字转成基础 HTML，再从 26 个高级动画模板中挑一个重构为带动画、轮播、交互的版本，专门适合 B 站视频素材和课堂教学。
>
> html-presentation-video 类 Skill 也明确面向“B 站讲解、知识分享、教程分镜”的 HTML 幻灯片，支持从逐字稿或导演稿生成视频友好的横版演示。

## 3. 参考项目的取舍

| 参考 | 采纳 | 不采纳 / 调整 |
|---|---|---|
| lieflat-html-design | 多主题、3:5 竖图、3:4 封面、AI 调用、PNG 截图 | 不复制其 11+11 组固定模板；改为“13 版式 × 8 主题”的组合式模板 |
| html-ppt-xhs-post | 竖版图文、暖色主题、卡片式信息 | 不做固定 9 页 / 底部圆点；改为可配置页数与比例 |
| any2card | 自动版式、竖版/横版 | 不在渲染器内做“自动决定版式”；由 OpenClaw 选择 `layout`，保持可控 |
| ppt-html-template | 零依赖、16:9、模块化、直接打开 | 增加 4:3 / 3:4 / 3:5 与动画运行时 |
| AI-Animation-Skill | 动画、B 站横版、教学场景 | 不内置 26 套动画；提供 6 种入场 + 环境动效，避免过度装饰 |
| html-presentation-video | 视频友好横版、分镜 | 不生成视频；输出可录屏/截图的 HTML |

## 4. 决策追溯

| 决策 | 结论 | 依据 |
|---|---|---|
| 项目类型 | `template`（前端模板） | 用户明确“作为前端模板出现”；developmentManager 类型表 |
| 依赖 | 0 npm dependencies | 参考“零依赖”与离线分发需求 |
| 内容模型 | 单一 `deck.json` | “一份内容”要求 |
| 封面/内容产物 | 4:3/3:4 仅封面，16:9/3:5 含内容 | 用户对四比例的用途定义 |
| 比例适配 | Container Queries + `cqw` | 画板内排版，避免视口断点污染 |
| 动画 | CSS + 轻量 runtime | 独立 HTML、无框架、可冻结 |
| OpenClaw | CLI + HTTP + Schema + Skill | “允许 OpenClaw 调用生成内容” |
| 截图 | 可选 Chrome headless | 参考“自动截图输出 PNG”，但不强制安装浏览器 |
| 文档 | 四件套 + 需求原文 + manifest | Go-Backend-Core 四段式 SOP |
