## 4. 决策

| 决策 | 结论 | 理由 |
|---|---|---|
| 是否打包字体 | 不打包 | 避免字体分发与体积问题；OFL 名称 + 系统回退已足够 |
| 自定义主题实现 | Token 覆盖，不新增 DOM 结构 | 保持渲染器稳定、导出可复现 |
| 背景效果 | 6 种 CSS 效果 | 覆盖纯色、渐变、柔光、网格、点阵、磨砂 |
| 字号策略 | ratio 基础倍率 + 用户倍率 | 默认解决移动端小字，用户仍可微调 |
| 浏览器测试 | 单一 CDP page target | 避免每页弹窗，截图更快 |
| 移动端默认 | 跟随窗口 | 横屏 16:9 / 竖屏 3:5，减少手动切换 |
