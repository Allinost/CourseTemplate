# 05 · 商用与素材合规

> 目标：模板本体、示例内容、字体引用与视觉素材都可安全用于商业项目。
> 结论：**不打包任何字体文件、不内置第三方图片、不使用外部图标库**；字体只引用开源字体名称，未安装时回退系统字体。

## 1. 字体策略

模板的字体栈优先引用以下**开源可商用字体**（均为 SIL Open Font License / OFL）：

| 字体 | 许可 | 用途 |
|---|---|---|
| Noto Sans SC / Noto Serif SC | SIL OFL 1.1 | 中文无衬线 / 衬线 |
| Source Han Sans SC / Source Han Serif SC（思源黑体 / 宋体） | SIL OFL 1.1 | 中文无衬线 / 衬线 |
| Inter | SIL OFL 1.1 | 西文无衬线 |
| JetBrains Mono | SIL OFL 1.1 | 代码 / 等宽 |
| LXGW WenKai（霞鹜文楷） | SIL OFL 1.1 | 手写感标题 / 正文 |

- 本项目**不附带字体文件**，只写 `font-family` 名称；浏览器使用用户本机已安装的字体，未安装则回退到系统字体。
- 如果后续需要把字体打包进产物，必须把对应 OFL 许可证文件一并放入 `assets/fonts/`，并在 `README` 中注明来源与版本。
- 不要改成 Windows / macOS 专有字体（如微软雅黑、苹方）作为**唯一**字体；它们只能作为系统回退。
- 不要使用来源不明的“免费字体”下载包；商用前核对许可证原文。

## 2. 图形与图片

- 示例封面/背景的太阳、圆环、网格、扫描线、柱状图、描边字全部由 CSS 绘制，无第三方图片。
- Studio 的图标是手写内联 SVG，无图标库依赖。
- `image` / `split.media.src` 支持用户传入图片；图片版权由调用方负责。建议：
  - 使用自有拍摄/设计素材；
  - 使用 CC0 / Unsplash / Pexels 等明确可商用来源，并保留来源记录；
  - 不要抓取搜索引擎图片、品牌 Logo、影视截图、付费图库预览图。
- 不要在模板中内置企业 Logo 或商标；示例中的 `ALLINOST ACADEMY` 仅为占位文本，交付客户时替换。

## 3. 代码与依赖

- 运行时、渲染器、构建脚本均为本项目原创，无 npm 运行时依赖。
- 不引入外部 CDN、Google Fonts、图标库或分析脚本；产物可离线使用。
- 参考项目的**设计思路**可以借鉴，但不复制其模板文件、图片、字体或代码。

## 4. 商用发布检查清单

- [ ] 替换示例组织名、作者、日期、Logo 与二维码。
- [ ] 确认所有 `image` / `media.src` 图片有商用授权或为自有素材。
- [ ] 确认自定义字体已安装/已授权；若打包字体，附 OFL 许可证。
- [ ] 不把客户未授权的品牌字体、商标、产品截图放入 deck。
- [ ] 生成物中的 `manifest.json`、`deck.json` 不包含敏感路径或密钥。
- [ ] 如对外分发 HTML，保留 Apache-2.0 许可证与版权声明。
