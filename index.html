启动模板工作台

Studio 需要本地 HTTP 服务（读取示例 JSON、调用导出接口、加载 ES Module）。直接双击 HTML 文件会受浏览器 file:// 安全限制。

01
在项目根目录运行 npm run dev
02
浏览器打开 http://127.0.0.1:4173/src/
03
左侧选主题/比例/外观，中间看预览，右侧编辑 JSON 或导出四种格式。
进入 Studio（需已启动服务） 阅读 README
当前是 file:// 打开方式，Studio 的示例加载、导出与字体模块会被浏览器拦截。请先运行 npm run dev，再访问 http://127.0.0.1:4173/src/。
